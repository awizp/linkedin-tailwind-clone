# LinkedIn Homepage - Responsive layout using TailwindCSS | Clone Repo

A clean and responsive LinkedIn clone built using HTML, CSS and TailwindCSS. Designed with a modern layout, fast loading and mobile friendly.

### Features

* Responsive Design: The layout adapts to different devices, ensuring a great user experience on desktop, tablet, and mobile devices.

### Languages used

* HTML: The structure of the web page.

* CSS: Used for styling and media queries to make the design responsive.

* TailwindCSS: To fetch modern styles to clean look.

### Installation

1. Clone this repository to your local machine

``````git clone https://github.com/awizp/linkedin-tailwind-clone.git``````

2. Open the folder and Run ```npm install``` for install debendencies.

3. Run ```npm run dev``` to run the application in your local host.
